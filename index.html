Personal Finance

A private budgeting tool for one person: me.

Personal Finance is a self-hosted app I built to track my own spending. It imports transactions from my own bank accounts so I can categorize them and see where my money goes. It is not offered to the public, and no one else can sign up or connect an account.

How it works

  • I connect my own bank accounts through Plaid.
  • The app reads transaction history (date, amount, merchant and category). It cannot move money.
  • Transactions are stored in a database on my own computer, where I categorize and review them.

Privacy

  • The only data collected is my own financial data, for my own use.
  • Data is never sold, shared or used for advertising.
  • Bank sign-in happens on Plaid's or the bank's own pages; the app never sees bank passwords.
  • I can disconnect a bank at any time, which revokes the app's access through Plaid.

Plaid's handling of data is described in the Plaid End User Privacy Policy.
